# Inbox

Capture without deciding. During review, either delete, file, link, turn into a TaskNotes task, or promote the note.

Open [[System/Bases/Inbox.base]] to process by kind or review state.

## Processing checklist

- Is it actionable? Create a TaskNotes task with a `project` link when relevant.
- Is it a durable idea? Promote it to a [[Notes/Permanent/Permanent Notes|Permanent note]].
- Is it source material? Create a [[Notes/Literature/Literature Notes|Literature note]].
- Is it Project context or reference? Move it and add a meaningful link.
- Is it no longer useful? Delete it.
