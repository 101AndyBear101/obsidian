# Example Decision — use a unified Inbox

## Decision

Use one Inbox and create processing views before adding separate queues.

## Context

Capture needs to be cheap; multiple folders make that harder.

## Rationale and evidence

A unified intake retains context while letting review decide the right destination.

## Alternatives considered

Separate task, idea, and reading inboxes.

## Consequences

Weekly review must include Inbox processing.
